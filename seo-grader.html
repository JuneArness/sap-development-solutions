SEO grader.

Grade any website’s SEO in about a minute, then walk the client through a clear, prioritized plan to fix it.

Internal tool for the SAP Development Solutions team. This page isn’t in the menu and asks search engines not to list it, but anyone with the link can open it. That’s fine: it only reads public websites, and your Google API key stays in your own browser. Don’t add passwords or private notes to this page.

Enter a website address, like example.com.
Test as
Google ranks sites by their mobile version, so start with Mobile.
Add page source for the full report Recommended. Grades content and local SEO, plus keyword and city checks.
  1. Open the client’s website in Chrome or Edge.
  2. Press Ctrl + U (Mac: Option + Cmd + U) to open the page source.
  3. Press Ctrl + A, then Ctrl + C to copy all of it (Mac: Cmd + A, Cmd + C).
  4. Click in the box below and press Ctrl + V (Mac: Cmd + V).

The code is only read, never run, and it isn’t sent anywhere.

Settings: Google API key Optional. Use one if Google says its free limit is busy.

Without a key, the test uses Google’s shared free limit, which is sometimes busy. A personal key is free. It’s saved only in this browser, never in the website files.

  1. Go to Google Cloud: PageSpeed Insights API and sign in.
  2. Create a project if asked (any name), then click Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key.
  4. Click the new key. Under Application restrictions, choose Websites and add your site address followed by /* (for example https://junearness.github.io/*). Under API restrictions, choose PageSpeed Insights API only. Click Save.
  5. Copy the key, paste it below, and click Save key.
